Learning-Based Control

Based on: “Neural Almost-Barrier Functions for Quantifying Safety in Learning-based Controllers”

  • Implemented safety-constrained reinforcement learning from a research paper
  • Built a Soft Actor-Critic (SAC) training pipeline in PyTorch
  • Designed reward functions and safety constraints
  • Achieved ~80% certified safety rate

Multi-Robot Formation Control (Nonholonomic Robots)

Based on: “Formation Control of Nonholonomic Mobile Robots Using Graph Theoretical Methods” (original paper)

  • Implemented the formation control method from the original paper (Laplacian-based consensus + time-scaling feedback)
  • Derived Kronecker-product matrix formulations to support variable robot counts and formation geometries
  • Developed a 2D multi-robot simulator in Python (NumPy, Matplotlib, Pygame) for formation and target tracking
  • Verified controller stability using the Hurwitz criterion and evaluated robustness under disturbances

    GitHub | Demo Video | My Report | Original Paper

Sensor Fusion & Perception

Project: Triton AI Autonomous Racing Lab (F1TENTH / EV Go-Kart)

  • Designed and implemented a perception pipeline for autonomous racing using camera-based object detection
  • Trained and evaluated YOLO models on 9,000+ labeled images under varying lighting and environmental conditions
  • Integrated perception outputs with ROS2-based multi-sensor fusion for real-time decision making
  • Adapted perception and control stack from F1TENTH platform to full-scale EV go-kart system
  • Improved robustness and detection stability for real-world autonomous driving scenarios

Text Adventure Game

A text adventure game with sound and scoreboard using Java Swing for elementary students. Users need to choose correct answers based on the questions before they lose all their HP. The game includes a cheerful opening and different sound effects for choosing right and wrong answers. The top 5 players’ scores will be saved and can be viewed on the starting page.
